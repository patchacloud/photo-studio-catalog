วิธีใส่รูปจริงของร้าน

  1. เปิดไฟล์นี้ด้วยโปรแกรมแก้ไขข้อความ แล้วหาส่วน const catalog = [...] ใกล้ท้ายไฟล์
  2. แต่ละรายการมีช่อง img: — ใส่ลิงก์รูปจาก Discord CDN, Imgur หรือที่โฮสต์รูปที่ใช้อยู่ แทนช่องว่าง
  3. แก้ name: เป็นชื่อทรงผม/ของตกแต่ง/ท่าที่ร้านใช้จริง เพื่อให้ลูกค้าอ้างอิงชื่อได้ตรงกัน
  4. บันทึกไฟล์แล้วอัปโหลดขึ้นที่โฮสต์เว็บ (เช่น GitHub Pages, Netlify) หรือแปะลิงก์ในดิสได้เลย
